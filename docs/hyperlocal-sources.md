# Hyper-local town content: sources

Every fact on the town pages traces to one of these public sources (checked 2026-11-19, America/Chicago). Facts that could not be verified were left out.

## Data used on every town page
- Housing (median year built, % before 1980, % 2000+, % 2010+, owner-occupied %, 65+ %): U.S. Census Bureau, American Community Survey 2020–2024 5-year estimates (table B25035, B25034, B25003, B01001), retrieved via https://censusreporter.org/ (release acs2024_5yr). Raw: cr.json, cr2.json, acs-summary.json.
- Population: 2020 Decennial Census, as cited on each town's Wikipedia page (ACS small-place population estimates differ, e.g. Mayflower).
- Census place codes: https://www2.census.gov/geo/docs/reference/codes2020/place/st05_ar_place2020.txt
- Distance from office: computed from 11 Arnett Ln, Conway (existing site data, milesFromHQ).
